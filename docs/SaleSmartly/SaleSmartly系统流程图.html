1产品总体架构

SaleSmartly 由 8 大核心模块组成，定位为"全渠道获客 + 客服 + 营销"一体化平台。与极光 LiveDesk 的纯客服定位不同，SaleSmartly 额外覆盖了营销群发、分流链接、广告分析、订单管理等业务场景。当前实测：Free 版账号，1 个聊天插件渠道已连接，支持 20+ 渠道类型接入。

2端到端客户服务流程

SaleSmartly 的服务流程分为 6 个阶段：渠道触达 → 消息聚合 → AI 优先响应 → 人工接管 → 客服工具处理 → 数据沉淀。与 LiveDesk 的 7 阶段流程相比，缺少独立的"状态流转"阶段（因为没有五态状态机），但增加了"营销触达"的回路——服务结束后可以通过群发和分流链接重新触达客户，形成闭环。

3AI 智能体编排架构

SaleSmartly 的 AI 架构是一个开放的"AI Agent 管理中枢"，支持接入多个外部 AI 平台的智能体。与 LiveDesk 只有一个内置 GPTBots Agent 的封闭模型完全不同。每个 Agent 可以独立学习与进化，企业可以根据业务需求灵活编排多 Agent 协作。

4全渠道接入体系

SaleSmartly 的渠道接入分为"官方通道"和"云托管号"两种模式。官方通道通过平台 API 授权接入，合规性高、功能完整；云托管号通过个人号云端托管方式接入，门槛低、启动快。同一平台（WhatsApp、Telegram、TikTok、LINE）同时支持双模式，让不同阶段的企业都能快速接入。

5营销与自动化流程

SaleSmartly 的营销模块是其区别于纯客服工具的核心差异点。消息群发支持 10+ 渠道、按标签/来源/行为分组推送；分流链接实现精准归因；自动化流程通过可视化编排实现复杂的业务逻辑。这三个能力组合形成了完整的"获客→转化→留存"闭环。

6数据分析体系

SaleSmartly 的报告模块覆盖客户分析、服务概览、在线时长、大报表、广告分析和 AI 分析 6 个维度。与 LiveDesk 的 10 子模块专业级分析相比，SaleSmartly 更偏"业务运营"视角，增加了广告分析（LiveDesk 无此能力），但缺少 P90/P95 分位统计和流量热力图等专业客服指标。

7三方产品能力对比

SaleSmartly、LiveDesk、自研系统三者的产品定位和能力侧重各不相同。下图用雷达图思路展示各产品在 8 个关键维度上的能力分布：渠道覆盖、AI 能力、营销能力、客服深度、数据分析、翻译能力、自动化、定制灵活性。
