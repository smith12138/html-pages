测试场景清单

  

    

      
1. 插件加载验证

      
确认页面右下角出现聊天气泡图标，点击后能正常展开聊天窗口。

      基础功能
      自动化
    

    

      
2. 消息发送测试

      
在聊天窗口中输入文本消息并发送，确认消息显示在对话列表中，后台能收到。

      基础功能
      手动
    

    

      
3. 自动回复验证

      
发送触发词（如"你好"），验证 AI 客服或自动化流程是否正确响应。

      AI客服
      自动化
    

    

      
4. 文件/图片发送

      
通过聊天窗口上传图片或文件附件，验证文件传输功能是否正常。

      多媒体
      手动
    

    

      
5. 窗口交互测试

      
测试聊天窗口的展开/收起、最小化、拖拽等交互行为是否流畅。

      UI/UX
      手动
    

    

      
6. 移动端适配

      
使用手机浏览器访问此页面，验证聊天插件在移动端的显示与交互。

      兼容性
      手动
    

    

      
7. 登录信息传参验证

      
通过上方表单设置登录信息后，在 SaleSmartly 后台确认客户档案已更新。

      JSSDK
      集成
    

    

      
8. 包网 API 查询验证

      
使用 API 查询工具查询玩家信息、充值/提现订单、奖励记录，验证接口连通性和数据。

      API
      集成
