3.2 首充流程（A 账号，亲手走）
  1. A 账号在 H5 发起充值 ₱200（选 GCash/QRPh，别真付）→ 生成充值单后喊我入账。
  2. 入账后看弹窗：Day1 应显示"20% BONUS"，₱200×20%=₱40 即时到账，余额 +₱40，Day2 解锁提示。
  3. 等 5 分钟进 Day2，再充 ₱300 → 50%，即时 ₱75 + 次日 05:00 到账 ₱75（看"待领/次日到账"文案对不对）。
  4. 再等进 Day3，充 ₱1000 → 100%，即时 ₱300 + 未来 7 天每天 05:00 各 ₱100（看 7 期进度条/日历）。
盯这些点找 bug：
  • 金额、比例、到账时间文案是否与上面一致（尤其"次日 05:00 / 每天 05:00"，别出现 16:10 之类）。
  • 未达标时（比如只充 ₱60）提示"还差 ₱40"是否正确、按钮是否置灰。
  • 各屏切换、进度、置灰是否正常；有无卡态/空白/报错。
  • 礼金"到账"展示——应是自动到账（负责人已定不做手动领取）；若还有"CLAIM/领取"按钮，是设计稿遗留，需前端去掉。
