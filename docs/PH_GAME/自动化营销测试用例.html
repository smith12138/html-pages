一、测试计划

1.1 计划概述
维度内容
测试对象两套营销引擎：规则活动圈选+分档赠金（retention）；旅程编排 draft/version/run + 人群集合+条件引擎+触达+优惠+运行期限（v2）
测试层次数据层（候选圈选/赠金对 DB 核对）+ 接口层（两套 REST + 签名信封 + 乐观并发）+ 管理后台页面 AM01-AM17
测试目标覆盖 T01-T70 验收；核心闭环场景 A（首存次日召回赠5）与场景 B（注册N分钟未充）；幂等/去重/预算/审批发布门禁/到期处理
参考口径契约 2.2（对象/进入方式/触发/画布/频控/幂等/状态机）+ PRD（人群§6/条件§7/期限§7.6/赠送§10/验证发布§11/70 用例§15）
1.2 测试范围
范围说明
纳入三种进入方式与允许触发组合、人群集合代数、时间窗/水位成熟、无事件Timer、优惠资格预占与充值后发放、消息/站内信、频控静默、幂等去重、预算门禁、审批发布门禁、运行期限与到期处理、状态机迁移、权限 RBAC、会员轨迹
排除短信供应商真实送达、Promotion 内部账本实现、邮件/Push/Webhook（首期不做）、AI 文案/多臂实验
依赖标签/指标服务覆盖凭据、号码映射、Promotion 资格预占/兑现、行为事件字典；未就绪时界面应显示「依赖未就绪」且禁止发布
1.3 测试策略
策略项内容
数据层核对dry-run 后取候选 source_facts 对 DB 同窗口 SQL 核对（选取口径/分档/去重）；赠金 action 对 promotion_grants/wallet_bonus_lots 核对
场景闭环场景A：造首存 D1、D2 无充值→D3 检查→资格预占→短信→充值→赠5；场景B：注册→>N分钟→未充值→赠金
幂等并发重复触发/Worker 重启/超时未知→验证不产生第二个 Participant/Action/消息/赠金/预算扣减；同键异载荷拒绝
边界口径严格区分 >N 与 ≥N、D2 末点排他、水位未齐 WINDOW_NOT_MATURED/DATA_WATERMARK_NOT_READY、UNKNOWN 不补零
期限到期持续循环无结束日 vs 指定日期范围（含末日、次日00:00排他关闭）；两种到期策略；已生效优惠必履约
接口安全v2 写操作双闸门：签名信封 + 乐观并发 expected_revision/state_version（CAMPAIGN_VERSION_CONFLICT）
1.4 环境·准入准出·风险
项内容
环境后台 http://13.251.234.1:8081（staging_qa）；retention DB=slot_platform；v2 DB=独立服务；需 wg0
准入两套 API 可用；可造测试用户；标签/Promotion/事件依赖服务就绪或显式标注未就绪
准出场景 A/B 完整链路通过；T01-T70 关键边界（时间成熟/水位/优惠幂等/期限到期）通过；P0 用例全绿；BUG 有单号
风险①dry-run 污染真实去重（BUG-1）②v2 的 validate/estimate/test/policies/audiences 无独立 admin REST，须研发确认入口 ③签名信封写操作需签名样例 ④探测曾产生脏活动 campaign_id=4 及 campaign3 草稿回退，待清理
