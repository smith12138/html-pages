会员列表

点击会员列表菜单，右边面板刷新默认列表。默认分页每页 10 条，可切 5/10/15/20/50/100。

核心筛选项

筛选取值 / 说明
会员会员ID、会员账号、注册IP、登录设备、手机号、邮箱、邀请ID、代理ID、真实姓名、CPF、EVP、CNPJ
用户状态全部、正常、登录锁定、充值锁定、游戏锁定
账号类型全部、正式、测试
VIP等级VIP0 - VIP10
会员层级默认层级、10元用户、30元用户、100元用户、500元用户 …
高级筛选默认收起。展开后含：总代、团队、小组、渠道、注册方式、注册时间、币种、会员标签、首充时间、最后充值、最后投注、金额区间

列表字段

会员账号、会员ID、手机号、邮箱、真实姓名、状态、账号类型、货币、VIP等级、会员层级、邀请ID、总代、团队、小组、渠道、注册方式、注册时间、首充金额、账户余额、当日（充值/提现/有效投注/输赢/优惠）、累计（充值/提现/充提差/有效投注/输赢/优惠）、最后充值时间、最后投注时间。

操作能力

  • 查询、重置、高级筛选展开/收起。
  • 新增会员、导出、批量操作。
  • 点击会员ID打开会员详情。
  • 单行操作：黑名单、登录锁定、充值锁定、提款锁定、登录密码重置、资金密码重置、修改VIP等级、设为代理、修改基本信息、实名相关。
  • 分页：支持每页条数、上一页/下一页、跳页。

1/ 新增会员

手机号注册　必填项：手机号、密码。
未填校验（输入框下方红字）：请输入正确的手机号 / 请输入正确的密码 / 两次输入的密码不一致
邮箱注册 暂不做　必填项：邮箱、密码。校验文案同上（邮箱）。

2/ 批量操作

未选目标数据时按钮默认置灰；选择 ≥1 条时点亮。

  • 拉入层级：当前会员层级在下拉框中置灰不可选。移除层级同理。
  • 会员标签：当前会员标签在下拉框中置灰不可选。移除标签同理。
  • 备注：批量写入备注。
  • 黑名单：范围为单选，下方输入框保持不变。

3/ 会员详情（弹窗）

聚合会员核心信息与快捷操作。展示内容：

  • 会员摘要：会员账号、会员ID、注册方式、用户状态。
  • 会员标签：高风险、活跃会员、大额注单、高价值会员、疑似套利、沉默唤醒、充值潜力、代理关联。
  • 账号与关系：用户状态、当前VIP等级、会员层级、币种。
  • 代理关系：上级账号、总代、团队、小组、渠道、是否代理、邀请人数。
  • 资料与验证：手机号、邮箱、生日、性别、KYC、真实姓名、身份ID、设备ID。
  • 钱包与资产：账户余额、钱包金额、冻结金额、钱包地址、首充金额、充值/取款/充提差/有效投注/输赢/优惠/佣金。
  • 注册与登录：首次登录时间、IP、终端、设备号、首充时间、最后充值时间、最后投注时间。
  • 备注：支持编辑会员备注。

快捷操作：加入黑名单、禁止投注、踢到大厅、修改密码、重置资金密码、修改等级、查看代理/团队/渠道、设备关联、IP关联、资金明细、账变记录。

加入黑名单 → toast 已拉入{用户锁定}，按钮置灰，客户端强制退出；再次登录 toast 账号异常，请联系客服
禁止投注 → toast 已启用禁止投注，按钮变浅蓝；再点 → 已取消禁止投注
踢到大厅 → 踢出且 10 分钟内不能进入该游戏厅；toast 已将用户{用户名称}踢出大厅
需求约束：代理关系、资料与验证、钱包与资产、注册与登录 这些分区后面的操作项都不要。修改密码/重置资金密码/修改等级逻辑与会员列表保持一致。

4/ 黑名单

点击【黑名单】弹出浮窗选择拉入某个黑名单；toast 已拉入黑名单{登录锁定}

5/ 密码相关

重置登录密码
默认系统随机生成，规则不限，最少 6 位。密码必填、其余非必填。校验：请输入密码 / 两次密码输入不一致。选站内信时向客户端 message 推送含 {站点名称}{密码值} 的通知。
资金密码重置
默认系统随机生成，只能 6 位。密码必填、其余非必填。校验同上。站内信文案固定。

6/ 修改VIP等级

会员账号、会员ID、当前会员等级置灰；仅「修改后会员等级」可编辑。

7/ 设为代理 暂不做

数据回显 + 全部非必填（入口按原型）。

8/ 修改基本信息

  • 数据回显。
  • 手机号、邮箱、生日、性别可修改；其余置灰不可修改。
  • 实名状态、身份ID、真实姓名：脱敏展示（中间脱敏）。
  • 成功 toast 修改成功。

9/ 实名相关 暂不做

字段：真实姓名、证件类型（CPF）、证件号码、处理结果。去掉查看处理结果与查看记录。

2

会员层级

包含两个页签：会员层级、层级会员管理。会员层级应用层级会员管理，参照 Panda 后台会员层级流程设计。

会员层级字段

序号、层级ID、层级名称、时间、充值金额、有效投注、用户输赢、优惠金额、投注天数、充值天数、存款次数、提款次数、VIP等级、备注、操作。

功能

  • 新增层级、编辑层级、删除层级、刷新。
  • 默认层级不可编辑、不可删除。
  • 新增/编辑需配置：层级名称、时长、充值金额、有效投注、用户输赢、优惠金额、投注天数、充值天数、存款次数、提款次数、关联VIP等级、备注。
新增层级：除 层级id、VIP等级、备注 外其余字段为必填；未填统一按 web 后台提示：输入框下方红字 请输入+{字段名}。
编辑层级：数据回显，层级id 置灰，其余可改。默认历史累计数据；增加时间选择字段，默认历史累计，选最近 n 小于等于 90 天。
删除层级：弹出二次确认 确认要删除{层级名称}吗？删除后将不可用。

层级会员管理

  • 展示：层级ID、层级名称、层级人数、备注。
  • 点击层级人数跳转会员列表，并按会员层级筛选。
  • 支持批量拉入/移除层级、上传文件、下载模板。
  • 添加会员 暂不做（按会员id模糊搜索，结果下拉选择拉入层级）；批量操作 暂不做。
3

会员标签

会员标签用标签分组，用于支持运营分群、风险识别和批量打标签。包含两个页签：标签列表、标签分组。

标签列表

字段：标签ID、标签名称、标签分组、会员人数、标签规则、备注、创建人、状态、操作。功能：按标签名称/分组/状态筛选；新增/编辑/删除标签、开启/关闭；批量拉入/移除标签、上传文件、下载模板、填备注。

新增标签规则：下拉框1为用户行为（登录、充值、提现，后续补齐）；下拉框2为判断条件（> < = >= <=）；输入框3为数值（不做特殊限制）；增加标签更新频率字段（单选：永久/月/天/h/min）。创建完标签后在输入框下方展示。批量操作 不做。
编辑标签：数据回显，除标签id外均可改。删除：二次确认 确认删除{标签名称}吗？删除后将不可用。

标签分组

字段：分组名称、标签数、用途说明、负责人、状态、操作。功能：新增/编辑/删除分组、开启/关闭、刷新。

新增分组：必填项分组名称，未填红字 请输入+{分组名称}，其余非必填。编辑：分组id置灰，其余可改。删除：二次确认 确认删除{分组名称}吗？删除后将不可用。
4

会员VIP管理

会员VIP配置，实施规则、保级晋级和会员其他触发，含 VIP配置 / 查看会员 两个页签。

VIP配置

字段：VIP等级、等级名称、等级Logo、累计存款升级条件、累计有效投注升级条件、上月累计存款保级条件、上月累计有效投注保级条件、返水点数、晋级奖励、操作。

展示规则：表头一行展示。实现方式：后端 SQL 默认写入 0-10 个等级（11 条数据），去掉等级 11。
编辑：数据回显；上传/修改等级Logo；配置升级条件、保级条件、返水点数、晋级奖励。VIP等级置灰。

查看会员

字段：VIP等级、成员数量、晋级奖励人次/金额、返水金额。仅查看。

反水、晋级、营销活动要有状态机：发放 → 领取 → 使用（领取状态）。字段：发放人数/金额、领取人数/金额、使用人数/金额、反水金额；可追溯、可管理、可使用。
5

非功能与规则

  • 敏感字段展示需脱敏，如手机号、钱包地址、设备信息。
  • 导出敏感字段需记录审批/审计日志。
  • 删除、黑名单、批量处理等高风险操作需二次确认。
  • 所有会员资料修改、VIP调整、层级/标签变更需记录操作人、时间、IP、前后值。
  • 列表查询需支持分页，默认每页 10 条，可切换 5/10/15/20/50/100 条。
6

验收标准

  • 运营可通过筛选条件定位会员，并打开完整会员详情。
  • 可完成新增会员、修改VIP等级、修改基本信息、黑名单处理。
  • 可配置会员层级、标签、VIP规则，并查看关联会员数量。
  • 批量层级/标签/黑名单/备注操作可创建任务，并可追踪日志。
  • 所有关键操作均有审计记录与结果反馈。
