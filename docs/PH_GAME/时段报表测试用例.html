一、测试计划

1.1 计划概述
维度内容
测试对象时段报表 26 项指标的取数口径、时间窗、刷新同步、币种切换/汇率确认、趋势缩略图、边界与权限
测试层次数据层（造数后指标对 DB 精确核对）+ 接口层（refresh/switch_currency/confirm_rate 及乐观并发）+ 管理后台页面
测试目标验证 26 指标口径正确、时间窗与成功率排除 pending 规则、趋势末点对齐 T、汇率与并发保护；覆盖 A01-A37 验收场景
参考口径PRD §2.1 时间窗、§2.2 刷新、§3.3 币种汇率、§4 公式、§4.1 成功率、§5.2 趋势、§6 边界权限、§7 一致性
1.2 测试范围
范围说明
纳入26 指标数据准确性；当日/昨日窗口；refresh 增量同步；switch_currency/confirm_rate；display_version 乐观并发；趋势 5 分钟点+精确末点；成功率 pending 排除；边界（零数据、跨日、精度）；权限门控
排除报表底层 8 个 source 的采集实现（由数据服务负责）；前端图表像素级还原；历史归档策略
依赖8 个 source（user/deposit/withdraw/bet/ledger/promotion_grant/referral/activity_reward）已同步；wg0 隧道；管理端 token
1.3 测试策略
策略项内容
数据层核对每指标造数后 refresh，取报表窗口 [today_start, cutoff_at) 对 DB 同窗口 SQL 聚合，逐笔比对（数量/金额/比率/去重口径）
造数解阻首充后手机验证墙用测试环境固定 OTP 123456（security/phone-verify）；提现族需关活动+清 1.5×本金打码（cs=3/450元每注）后走 approve 自动出款
成功率验证显式构造 success/failed/expired/processing 混合订单，验证分母=已结束(含 expired/failed)、排除 pending
并发验证读取 display_version 后并发 switch_currency/confirm_rate，验证 REPORT_VERSION_CONFLICT 乐观锁
趋势验证校验点间距=300s、末点精确对齐 cutoff、累计非降、末点值==表值
1.4 环境与准入准出
项内容
环境后台 http://13.251.234.1:8081（staging_qa）；DB slot_platform@13.251.234.1:55432（只读）；需 WireGuard wg0
准入8 source 均 updated；接口可用；可造数账号可注册/充值/提现/下注
准出P0 用例 100% 通过；26 指标数据准确性用例全绿；已知 BUG 有单号并复测；遗留项记录在测试结论
风险汇率无上限 BUG 会污染展示（切非基准币金额塌 0）；提现族造数受打码门控，需研发关活动配合
