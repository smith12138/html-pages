一、单轮提问清单（覆盖 13 个功能块）
1开场 / 身份识别
你好，我账户上想找点帮助
Hi, I need some help with my account
实测✅回招呼语 + 功能菜单（Account / Deposit / Withdrawal / Wallet / Bet history / Promotions）
2账户类（注册 / 改密码 / 找回）
如何注册一个新账号？
How do I register a new account?
实测✅输入手机号 → 设置字母+数字的密码 → 点 Register/Login，并提示注册前核对手机号密码
如何设置 / 修改我的登录密码？
How do I set or change my login password?
实测✅Profile/Account → Account → Password → 输入并确认新密码 → Confirm
我忘记密码了，怎么重置？
I forgot my password, how can I reset it?
实测✅登录页点 Forgot → Get Code 收短信验证码 → 输码 → 设新密码 → Confirm（并提示登录密码=提现密码）
3充值 How-to
我要怎么充值到账户里？
How do I deposit money into my account?
实测✅Tap Deposit → 选 GCash/Maya → 输金额 → Continue → 付款 → 等到账（含 Quick Flow 图示）
4提现 How-to
我要怎么提现我的奖金？
How do I withdraw my winnings?
实测✅Profile → Withdrawal → 选/输金额 → Continue → 验证登录密码 → Confirm，通常 10 分钟内到账
5绑定钱包 How-to
我要怎么绑定我的 GCash 钱包用于提现？
How do I bind my GCash wallet for withdrawal?
实测✅Profile → Bank 标签 → Add Withdrawal Account → 选 GCash/Maya → 填手机号+登录密码 → 提交
6优惠活动
现在有哪些优惠活动？
What promotions are available now?
实测✅列出 Deposit Bonus、Referral Reward、Registration Bonus，并指引到 Promotions 页看详情

⚠️ 现场斟酌 —— 以下为已知缺陷（第 11、12 块属此类，客户追问可答"已提单、优化中"）
  • 时间 / 汇总查询（第 11 块）：会答错，只报最近 1 笔；"今天"会拿旧充值冒充。
  • 奖励 / Bonus 查询（第 12 块）：会回"查无奖励记录"（假阴性）。
  • 账户状态 / VIP（7⑤）：只返用户名+ID，不明说 active/VIP。
  • 一句话同时给 UID + 问题：会被吞（务必分两条）。
  • 要求 AI "说简单点 / 换个说法"：会退回主菜单。
