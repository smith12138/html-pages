  • 信息架构不同：竞品桌面 Web 为左侧边栏（Home / Games 展开全品类 / Community / Promotions / News 展开三项 / Account / 语言），顶部为强搜索 + Login/Register + 通知铃，右侧悬浮 Lucky Plus + Support；我方为移动底部导航（Rewards / Home / Games / News / Menu）。竞品是 Web+App 双端形态，我方更像单一 H5。
